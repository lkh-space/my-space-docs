# PRD-007 릴리스 범위와 우선순위

## 이 문서는

- **목적**: [PRD-002 요구사항과 범위](prd-002-requirements-scope.md)와 [PRD-003 사용자 스토리와 수용 기준](prd-003-user-stories.md)을 어떤 릴리스(구현 단계)에 담을지, 각 단계 안에서 무엇을 먼저 구현할지, 이번에 무엇을 하지 않을지 정한다.
- **범위**: 요구사항 자체와 전체 우선순위는 [PRD-002](prd-002-requirements-scope.md)가 기준이다. 이 문서는 기능 간 의존성과 아키텍처 기반 구축 순서에 따른 릴리스별 배분을 다룬다.
- **대상 독자**: 프로젝트 소유자, AI 에이전트
- **작성 시점**: [PRD-002](prd-002-requirements-scope.md)·[PRD-003](prd-003-user-stories.md)이 정리된 뒤, 디자인 및 개발 착수 전.
- **등급**: 선택 — 다수의 공간과 도구를 단계별로 나누어 구현·검증하기 위해 작성한다.

## 우선순위 기준 [필수]

[근거: 실무 관행 · Agile Business Consortium MoSCoW Prioritisation]

| 값 | 의미 | 이 프로젝트에서의 판단 기준 |
|---|---|---|
| Must | 해당 릴리스의 핵심 목표를 달성하는 데 필수적인 기능 | 하위 도구나 공간이 의존하는 공통 기반(네비게이션·디자인 개편, 스케줄러, 핵심 공간·도구) |
| Should | 중요하며 해당 릴리스 안에서 함께 완성할 기능 | 공통 기반 위에 얹히는 개별 날짜 유형 확장, 보조 개발·계산 도구, 테스트 계정 환경 |
| Could | 일정이나 복잡도 조정이 필요할 때 다음 마일스톤으로 넘길 수 있는 기능 | 외부 API 의존 기능 또는 부가적 확장 기능 |
| Won't | 이번 v2에서는 하지 않는다 | [PRD-001](prd-001-product-overview.md) 비목표 및 [PRD-002](prd-002-requirements-scope.md) 제외 범위 |

## 릴리스 계획 [필수]

전체를 한 번에 구현하지 않고, **기반 구조·기존 기능 재배치 → 공간 신설(관리·피드) → 도구 확장(개발·이미지·문서·계산) → 테스트 계정 환경 구성**의 3개 릴리스(세부 8단계)로 나누어 순차적으로 완성한다.

| 릴리스 | 목표 | 대상 에픽 | 포함 범위 요약 |
|---|---|---|---|
| **v2.1 — 플랫폼 재편 및 공간 완성** | `공간`/`도구` 정보 구조와 디자인을 전면 개편하고, 홈랩 Catch-up 인프라 위에 `관리`와 `피드` 공간을 완성한다 | E-01, E-02, E-03, E-04 | 1단계: 네비게이션·디자인 개편 및 노트·AI·PDF·DBML 재배치<br>2단계: `공간 › 관리` (공통 날짜 모델 3유형, 홈랩 Catch-up·알림)<br>3단계: `공간 › 피드` (RSS 수집, Readability 본문 추출, 키워드 필터) |
| **v2.2 — 개발·미디어·문서 도구 확장** | 브라우저 파서(NoSQL 스키마·cron·정규식·EXIF)와 Web Worker·WASM 이미지 처리, 하이브리드 문서 도구를 완성한다 | E-05, E-06 | 4단계: `도구 › 개발` (NoSQL 스키마 시각화, cron 파서, 정규식 AST, JWT, timestamp)<br>5단계: `도구 › 이미지` (EXIF 바이너리 파서·제거, Web Worker/WASM 변환)<br>6단계: `도구 › 문서` (PDF 프론트/백엔드 하이브리드 다듬기, 마크다운 일회성 변환) |
| **v2.3 — 일상 계산 도구·PWA 및 테스트 계정** | 정밀 금융·정산·단가·영업일 계산기와 PWA 오프라인 지원, 외부 방문자용 테스트 계정 환경을 완성한다 | E-07, E-08 | 7단계: `도구 › 계산` (더치페이, 실수령액, 대출·적금, PWA 단가 비교, 영업일 계산)<br>8단계: 외부 방문자 체험용 테스트 계정, 샘플 데이터 및 데이터 격리 |

## 이번에 하지 않는 것 [필수]

| 항목 | 이유 | 다시 검토할 시점 |
|---|---|---|
| 다중 사용자 실시간 협업·공유 | 테스트 계정을 통한 외부 방문자 체험만 지원하며, 여러 사용자가 데이터를 함께 편집하는 기능은 제품 목적 밖이다 ([PRD-001](prd-001-product-overview.md)) | 검토 안 함 |
| 도구 간 파이프라인 체이닝 | 각 도구는 단일 목적의 즉각적인 입력→출력 완결성을 유지한다 | 검토 안 함 |
| 수동 입력 가계부, 별도 스니펫·독서 공간, 별도 프롬프트 보관함 | 입력 부담이 크거나 `공간 › 노트`의 폴더·태그·템플릿으로 충분히 대체 가능하다 | 검토 안 함 |
| 피드 아티클 → 노트 원클릭 스크랩 연동 | [PRD-002](prd-002-requirements-scope.md)에서 `나중에`로 분류한 공간 간 심화 연동 기능이다 | v2.3 완료 후 필요시 검토 |
