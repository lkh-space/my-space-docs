# PRD-002 요구사항과 범위

## 이 문서는

- **목적**: `my-space` v2가 충족해야 할 기능·비기능·제약 요구사항을 하나씩 ID(`REQ-`)를 붙여 정의하고, 이번 v2 범위에 포함할 항목과 제외할 항목을 확정한다. 요구사항 목록과 `REQ-` ID의 **기준 문서**다.
- **대상 독자**: 프로젝트 소유자, AI 에이전트
- **작성 시점**: [PRD-001 제품 개요와 비전](prd-001-product-overview.md) 작성 직후. 사용자 스토리([PRD-003](prd-003-user-stories.md))와 비기능 요구사항([PRD-006](prd-006-nfr.md))보다 먼저 쓰고, 개발 중 요구가 바뀌면 갱신한다.
- **등급**: 필수 — 모든 프로젝트

## 범위 [필수]

| 구분 | 항목 | 이유 |
|---|---|---|
| 포함 | 카테고리 및 정보 구조 재편 (`공간` / `도구`) 및 UI·UX 디자인 전면 개편 | 포맷·기술 기준 혼재를 해결하고 기능 확장 시 일관된 탐색 경험과 완성도 높은 UX를 제공한다 |
| 포함 | 공간 › 노트 (마크다운 문서 스튜디오 계승 및 배치) | 폴더·태그·전문 검색·버전 Diff·복원 등 핵심 지식 저장소다 |
| 포함 | 공간 › 피드 (키워드 규칙 기반 기술 블로그·뉴스 RSS 리더 + 원문 추출) | 관심 키워드 우선순위와 제외 키워드 필터링으로 읽을 글을 선별하고 원문을 열람한다 |
| 포함 | 공간 › 관리 (공통 날짜 모델 3유형: 정기 결제·구독, 만료, D-day·기념일) | 놓치면 곤란한 날짜와 월 구독료를 단일 날짜·주기 모델 위에서 관리한다 |
| 포함 | 홈랩 비-상시 구동 대응 스케줄 보정(Catch-up) 및 알림 채널 추상화 | 홈랩 서버가 꺼졌다 켜져도 누락된 수집·만료 판별을 보정하고 인앱·외부 알림으로 연결한다 |
| 포함 | 공간 › AI (실시간 음성·텍스트 스트리밍 비서 유지) | 다른 공간과 분리된 독립 AI 공간으로 유지한다 |
| 포함 | 도구 › 문서 (PDF 병합·분할·암호 해제 프론트/백엔드 하이브리드 처리, 마크다운 일회성 변환) | 일반 PDF 조작·사전 확인은 브라우저, 암호화 PDF(`qpdf`)는 백엔드에서 처리하고, 저장 없는 마크다운 즉시 변환을 제공한다 |
| 포함 | 도구 › 이미지 (Web Worker·WASM 기반 압축·리사이즈·WebP/AVIF 변환, EXIF 파싱·제거) | 대용량 이미지 스레드 분리 처리와 EXIF 메타데이터 조회·제거를 제공한다 |
| 포함 | 도구 › 개발 (DBML 및 NoSQL 스키마 시각화 + cron 해석기, 정규식 AST 시각화, JWT 디코더, timestamp 변환) | 자주 쓰는 RDB·NoSQL 스키마 시각화 및 파서·변환·검증 유틸리티를 한곳에 모은다 |
| 포함 | 도구 › 계산 (더치페이 최소 송금 정산기, 연봉 실수령액, 대출·적금 이자, PWA 단가 비교기, 날짜·영업일 계산기) | 일상 정산·금융·단가·영업일 계산과 모바일 오프라인(PWA) 동작을 지원한다 |
| 포함 | 외부 방문자용 테스트 계정 및 데이터 격리 | 외부 접속이 열려 있을 때 방문자가 주 사용자의 개인 데이터 노출 없이 기능을 체험할 수 있게 한다 |
| 나중에 | 공간 간 심화 연동 및 추가 고도화 (예: 피드 글을 노트로 즉시 스크랩 등) | 기본 공간과 도구를 먼저 완성한 뒤 후속 단계에서 확장한다 |
| 제외 | 일상과 업무에서 활용하지 않는 기능 | 사용 빈도가 낮거나 지속해서 쓰기 어려운 기능은 범위에서 제외한다 ([PRD-001](prd-001-product-overview.md)) |
| 제외 | 다중 사용자 간 실시간 협업·공유 기능 | 테스트 계정을 통한 기능 체험만 지원하며 사용자 간 공동 편집이나 일정 조율은 다루지 않는다 |
| 제외 | 기존 공간과 중복되는 별도 기능 및 과도한 파이프라인 | 노트의 태그·템플릿·Diff로 대체 가능한 기능이나 도구 체이닝·무거운 잡 큐 구성은 제외한다 |

## 요구사항 목록 [필수]
