# ADR-0010 v2 RustFS 채택과 호환성 검증 경계

## 결정 상태

승인됨 — 2026-11-19 사용자 검토 및 명시적 승인 완료.
대체 관계: ADR-0006을 대체한다. 기존 결정 본문은 역사 기록으로 보존한다.

## 맥락과 결정 동인

RustFS 채택 방향은 유지한다. ADR-0006은 v1 전환 기록이며 100% 호환·보안 패치 위험 제거·자원 절감·코드 무수정 같은 표현을 v2의 검증 완료 사실로 사용할 수 없다. 라이선스 선택 자체가 향후 유지보수나 보안을 보장하지 않는다.

## 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| RustFS 채택 + 사용 기능별 호환성 검증 | 기존 S3 기반 구조 유지, 검증 범위 명확 | 릴리스별 호환성·복구 시험 필요 |
| latest와 완전 호환을 전제로 즉시 교체 | 초기 작업 감소 | 재현성·호환성·롤백 근거 부족 |

## 결정

v2의 노트 본문·리비전 객체 저장소로 RustFS를 채택하되 배포는 검증한 버전 또는 이미지 digest로 고정한다. S3 Put/Get/Delete/List, 오류 응답, 인증·권한, 사용 시 Presigned URL, 재기동 보존·백업 복원을 검증한다. 기능 호환성과 성능은 시험 결과로 판단한다. 사용하지 않는 S3 기능까지 호환한다고 단정하지 않는다.

v1의 MinIO 데이터 이전·MINIO_* 환경변수 유지·서비스 주소 변경은 기존 전환 런북의 범위다. v2의 설정 이름과 배포 주소는 후행 BE/INF 문서에서 명시하며 SDK가 특정 환경변수 접두사를 요구한다고 간주하지 않는다. 기존 데이터 이전 여부를 확인한 뒤 필요한 경우에만 마이그레이션·롤백을 수행한다. 과거 보안 지원 정책 주장은 결정 당시의 배경 기록이며 현재 정책 확인을 대신하지 않는다.

## 결과와 검증

스토리지 방향은 유지하면서 무검증 보장을 제거한다. 인프라 변경 영향과 자원 사용량은 배포 전 시험으로 확인한다. 기존 런북은 [RustFS 전환 가이드](file:///Users/limkeunhyeok/workspace/homelab-infra/docs/rustfs-migration-guide.md)를 참조한다.
