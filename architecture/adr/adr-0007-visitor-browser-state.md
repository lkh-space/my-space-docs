# ADR-0007 방문자 체험 상태의 브라우저 메모리 격리

## 결정 상태

승인됨 — 2026-11-19 사용자 검토 및 명시적 승인 완료.
대체 관계: ADR-0004을 대체한다. 기존 결정 본문은 역사 기록으로 보존한다.

## 맥락과 결정 동인

승인된 PRD-003 US-024, PRD-005 FN-025 및 DSN-009는 방문자의 변경을 브라우저 메모리에만 반영하고 새로고침하면 초기화하도록 정한다. ADR-0004의 서버 세션별 메모리·TTL 방식은 저장 위치와 수명이 다르다.

## 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 브라우저 메모리 체험 상태 | 승인된 초기화 동작과 일치, 서버 세션 저장소 불필요 | 서버 영속 쓰기와 체험 어댑터를 구분해야 함 |
| 서버 세션별 메모리 | 서버의 CRUD 로직 재사용 가능 | 새로고침 초기화 요구와 불일치, 세션 공유·TTL 관리 필요 |

## 결정

브라우저의 체험 어댑터가 초기 샘플을 복제해 읽기·생성·수정·삭제·검색을 처리한다. 변경분은 localStorage·IndexedDB·서버에 저장하지 않는다. 새로고침·명시적 초기화·탭 종료 시 폐기한다. SPA 화면 이동 중에는 해당 탭의 메모리 상태를 유지한다.

Authelia ForwardAuth 인증은 유지한다. 서버는 방문자에게 별도 읽기 전용 샘플만 제공하고 주 사용자 리소스 조회 및 공간 영속 쓰기를 거부한다. UI 분기는 서버 인가를 대체하지 않는다. 방문자의 AI 샘플과 노트 저장 체험도 같은 브라우저 상태를 사용하며 주 사용자 RAG·저장소·Slack·인덱싱 큐로 연결하지 않는다. 실제 외부 AI 호출 체험은 별도 승인 범위가 정해지기 전 활성화하지 않는다. 일회성 도구는 PRD-005대로 동일하게 제공하며 PDF의 일시적 서버 처리는 공간 영속 쓰기와 구분한다.

## 결과와 검증

서버 세션 메모리와 프로세스 간 공유가 필요 없지만, 체험 어댑터가 화면 동작을 재현해야 한다. 두 탭 간 변경 격리, 새로고침 초기화, 저장소 미기록, 주 사용자 ID 직접 요청 거부, 방문자 외부 알림·색인 미발행을 검증한다.
