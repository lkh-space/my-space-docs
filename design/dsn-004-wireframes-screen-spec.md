## 대표 화면 명세

- **홈 (SCR-001)**: 좌측 240px 공통 탐색(L1 사이드바), 상단 제목/알림 바, 본문 3열 대시보드 그리드(최근 노트 2열, 피드/일정/AI 요약 1열), 하단 빠른 도구 실행 바. 각 요약 카드 로딩 실패 시 독립적 재시도 버튼 제공.
- **노트 (SCR-010)**: 3열 레이아웃(폴더 트리 220px, 노트 목록 280px, 편집/미리보기 패널). 상단 뷰 모드 토글로 에디터 단독 / 스플릿 뷰(에디터+미리보기 동시) / 미리보기 단독 3종 모드 전환 및 단축키 안내. 자동 저장 인디케이터(`저장 완료`), 마크다운 툴바. 모바일에서는 목록·편집·미리보기를 1열 탭 패널로 전환. 복원은 버전별 diff 비교 모달 후 확인.
- **피드 (SCR-020)**: 2열 구조(구독 채널 목록, 피드 카드 리스트). '모두 읽음' 일괄 처리 버튼. 4대 모달 다이얼로그(키워드 필터 모달, 키워드 설정 모달, 제외 규칙 모달, 삭제 확인 모달) 및 태그 필터링.
- **도구 탐색 (SCR-050)**: 카테고리 탭(문서, 이미지, 개발, 계산), 목적을 직관적으로 설명하는 진입 카드 그리드. 마케팅 배너·유료 플랜 배제.
- **PDF 도구 (SCR-051)**: 파일 드롭존, 선택된 파일 리스트 카드(파일명, 용량, 페이지 수, 드래그 앤 드롭 재정렬 핸들 `:::`, 위/아래 이동 버튼, 개별 삭제), 작업 완료 후 하단 고정 다운로드 패널(`Merge Result Panel`). 암호화된 파일의 경우 백엔드(qpdf) 처리 사전 안내.
- **Cron 생성기 (SCR-071)**: 자연어/주기 선택 기반 양방향 빌더(15분마다, 매시간 특정 분, 매월 특정일, 고급 커스텀) 카드 및 실시간 Cron 식 변환 + 다음 실행 시각 5회 미리보기.

## 시안과 연동

- **Figma v2 (`my-space-v2`) 시안**: `01 · 디자인 시스템` 및 `02 · 제품 화면` (Flow 1: 노트 뷰 전환, Flow 2: 피드 모달 4종, Flow 3: Cron 빌더, Flow 4: PDF 병합 드래그 및 결과 패널 프로토타입 구현 완료).
- 레거시 Stitch 검토 프로젝트([Stitch](https://stitch.withgoogle.com/projects/18082781618690839750)) 대비 Figma v2 확정 시안으로 전면 이관됨. API operationId와 오류 코드는 후속 계약 확인 후 연결한다.
