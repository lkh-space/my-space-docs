## 대표 화면 명세

홈: 좌측 공통 탐색, 상단 제목/알림, 본문 최근 노트와 일정, 보조 피드·AI, 하단 빠른 도구. 각 요약 실패는 해당 영역에서 재시도한다.

노트: 탐색 → 문서 목록 → 편집/미리보기. 모바일에서는 목록·편집·미리보기를 한 번에 한 패널로 표시한다. 저장 상태를 실제 결과와 맞추고 복원은 선택 버전과 현재 버전의 차이를 보여준 뒤 확인한다.

도구 탐색: 카테고리 선택 → 목적을 설명하는 카드 → 작업 화면. 마케팅 배너·유료 플랜을 넣지 않는다.

PDF: 파일 선택 → 선택 파일 목록 → 순서 조정/설정 → 실행 → 결과. 드래그 외 위/아래 이동 버튼 제공. 암호화된 파일의 서버 처리 필요성을 해당 시점에 안내한다.

## 시안과 연동

[Stitch 검토 프로젝트](https://stitch.withgoogle.com/projects/18082781618690839750). 실제 생성 화면 목록은 README의 검토 현황을 참조한다. 위 전체 화면군은 설계 범위이며 모든 시안이 완성되었다는 의미가 아니다. API operationId와 오류 코드는 후속 계약 확인 후 연결하며 임의 정의하지 않는다.
