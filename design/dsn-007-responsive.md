# DSN-007 반응형 디자인

> v2 검토 초안. 사용자 승인 전이며 구현 완료 또는 접근성 검증 완료를 뜻하지 않는다.

## 지원 환경과 브레이크포인트

[PRD-006](../product/prd-006-nfr.md)의 검증 폭은 1440/768/375px이다. 다음 전환점은 디자인 제안이며 PRD의 테스트 폭과 구분한다: 모바일 320~767px, 태블릿 768~1199px, 데스크톱 1200px 이상.

## 화면별 변화

| 영역 | 데스크톱 | 태블릿 | 모바일 |
|---|---|---|---|
| 공통 탐색 | 240px 사이드바 | 접을 수 있는 탐색 | 홈·공간·도구·알림 진입 |
| 홈 | 요약 2~3열 | 2열 | 1열 |
| 노트 | 탐색·목록·편집 패널 | 목록 접기 | 목록/편집/미리보기 전환 |
| 도구 | 설정·결과 병렬 가능 | 공간에 따라 세로 | 입력 → 결과 세로 흐름 |
| ERD·정규식 | 넓은 캔버스 | 영역 확대·이동 | 전용 캔버스·확대·맞춤, 텍스트 대안 |

## 확인 항목

320px 리플로, 200% 확대, 375/768/1440px에서 필수 행동 접근, 하단 탐색·키보드가 입력/버튼을 가리지 않는지 확인한다. 2차원 캔버스는 영역 안에서 스크롤하고 페이지 전체 오버플로와 구분한다. 검증은 아직 수행하지 않았다.


## 검토 체크리스트

- [ ] 사용자가 시안과 규칙을 검토했다
- [ ] 관련 화면과 문서의 내용이 일치한다
- [ ] 미결정 항목을 확정하거나 후속 작업으로 구분했다
