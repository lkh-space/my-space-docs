# my-space v2 디자인 검토

현재 제품은 v1, 이 폴더는 v2 전면 개편 초안이다. 모든 문서는 review 상태이며 승인된 PRD를 변경하지 않는다.

## 검토 순서

1. Stitch 대표 화면에서 분위기·정보 밀도·탐색을 확인한다.
2. 디자인 시스템 보드에서 글자·색·버튼·입력 상태를 확인한다.
3. DSN-001의 방향을 검토한 뒤 전체 화면 상세화를 진행한다.

## 검토할 질문

- 전체가 읽기 편하고 차분한가? 더 조밀하거나 더 넓었으면 하는가?
- 공간과 도구를 쉽게 구분하는가?
- 작업 시작과 결과 확인 위치가 명확한가?
- 모바일에서 핵심 작업을 수행할 수 있는가?
- 라이트 모드 방향과 강조색이 적절한가? 다크 모드가 초기 범위에 필요한가?

## 완료 범위와 후속 작업

현재 산출물은 방향·전체 화면군·기본 시스템의 검토 초안이다. 화면별 모든 상세 명세, 모든 반응형 시안, 구현 검증은 후속 작업이다. 사용자 방향 검토 전 전체 화면을 확정하지 않는다.

디자인 원본은 이 폴더에서 관리한다. 승인 후 프론트 DESIGN.md를 v2 구현 기준으로 개정한다. 기존 PRD의 DESIGN.md 참조와 운영 인덱스는 승인 시 함께 정합성을 확인한다. DSN-010은 확정 결정의 변경이 생길 때 작성한다. 커밋·푸시는 수행하지 않는다.
