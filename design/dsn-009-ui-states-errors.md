# DSN-009 UI 상태와 오류 상태

> v2 정식 승인본. Figma v2(디자인 시스템 및 제품 화면) 확정 시안 기준.

## 상태 분류와 공통 표시 규칙

| 상태 | 표시 | 다음 행동 |
|---|---|---|
| 초기/부분 로딩 | 해당 영역 자리 표시·진행 안내 | 완료 대기, 실패 시 재시도 |
| 처리 중 | 행동 버튼에 진행 상태·중복 실행 방지 | 지원되는 작업만 취소 제공 |
| 첫 사용 빈 상태 | 들어올 콘텐츠와 첫 행동 설명 | 첫 노트 작성·RSS 등록 |
| 검색 결과 없음 | 조건을 포함한 안내 | 검색·필터 수정 |
| 입력 오류 | 필드 옆 오류와 필요 시 요약 | 입력 유지·수정 |
| 처리 실패 | 원인과 재시도 가능 여부 | 재시도 |
| 부분 실패 | 실패한 카드/영역만 오류 표시 | 해당 영역 다시 불러오기 |
| 권한 없음 | 로그인 또는 접근 제한 안내 | 적절한 진입점으로 이동 |
| 찾을 수 없음 | 삭제/없는 대상 안내 | 목록으로 이동 |
| 서버 연결 실패 | 공간 데이터를 불러오지 못함 | 다시 연결·사용 가능한 로컬 도구 |
| 오프라인 | 네트워크 상태와 가능한 기능 구분 | 캐시된 로컬 도구 사용 |
| 성공 | 저장/복사/다운로드 준비 결과 | 다음 행동 |
| 체험 임시 변경 | 서버에 저장되지 않음을 지속 안내 | 새로고침 초기화 인지 |

## 오류 문구 초안

“파일이 50MB를 초과했습니다. 더 작은 PDF를 선택해 주세요.”(PRD-006 제한)
“서버에 연결할 수 없어 노트를 저장하지 못했습니다. 연결 후 다시 시도해 주세요.”
“검색 결과가 없습니다. 검색어나 태그를 바꿔 보세요.”
“체험 중 변경한 내용은 이 화면에서만 유지되며 새로고침하면 초기화됩니다.”

## 오류 코드 연결

백엔드 오류 계약 확인 전 코드 매핑은 미정이다. 새 코드를 디자인 문서에서 만들지 않는다. 입력 오류·권한 문제·서버 장애를 동일한 메시지로 합치지 않는다. 원본 입력과 편집 내용의 유지 정책은 기능 명세에 맞춰 검토한다.
